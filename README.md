# 📖 Overview

Loan Knowledge Base is a structured documentation project designed to transform relational loan datasets into a high-quality knowledge base.

Instead of indexing raw CSV files, this repository provides comprehensive documentation that enables both humans and AI systems to understand:

- Database architecture
- Table relationships
- Business logic
- SQL examples
- KPI definitions
- Analytics workflows
- Dashboard ideas
- Prompt engineering for AI assistants

The documentation is specifically optimized for Retrieval-Augmented Generation (RAG), making it suitable for AI-powered SQL assistants.
